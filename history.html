History

How this site changed.

Screenshots of every version of this website, from the first portfolio to today. Click a picture to open it at full size.

  1. 01Nov 2025 – Nov 2026

    The first portfolio

    A dark, game-style portfolio: a hub, the portfolio with skills and projects, services, a resume written as a quest log and the web apps, plus a second theme called "Enter the void". It is kept as a frozen archive and no longer part of the site.

  2. 026 Nov 2026

    A box and six cursors

    A fresh start: an empty page with one box. A click lets six cursors out, and they wander around. Nothing else yet.

    Pull request 14

  3. 036 Nov 2026

    Bots build the page

    The cursors get jobs and name tags. They build the first card, one step per click.

    Pull request 17

  4. 046 Nov 2026

    A real landing page

    Hero, About, Experience, Skills and Contact build themselves while you scroll. The CV became a page (German and English) instead of a PDF.

    Pull request 21

  5. 056 Nov 2026

    Projects as mockups

    Dienstplan as a tilted phone with a real screenshot, a poster for Aphonia and all eight renders.

    Pull request 22

  6. 066 Nov 2026

    The swarm finale

    Press a button and a few cursors become hundreds that gather into the five skill layers.

    Pull request 23

  7. 0710 Nov 2026

    Five bots

    Two more bots (accessibility and motion) and a layout bot that builds with real sizes, padding and grids. The last dark version.

    Pull request 26

  8. 0812 Nov 2026

    Editorial

    The redesign: light paper, Space Grotesk, a giant name and a box that travels to the corner and becomes the bots' home. Every page now shares one design.

    Pull request 27
