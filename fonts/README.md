# Fonts

Self-hosted so the site makes no request to Google (privacy). All are licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org).

- `space-grotesk-latin-var.woff2`: Space Grotesk (variable, weight axis 300 to 700, latin subset), by Florian Karsten. https://github.com/floriankarsten/space-grotesk
  Used for everything on the homepage (weights 400, 500 and 700).
- `inter-latin-var.woff2`: Inter (variable, latin subset), by Rasmus Andersson. https://github.com/rsms/inter
  Only used by `cv.html` now (the homepage switched to Space Grotesk).
- `instrument-serif-italic-latin.woff2`: Instrument Serif Italic (latin subset), by Rodrigo Fuenzalida
  and Jordan Egstad of Instrument. https://github.com/Instrument/instrument-serif

Subsets are the files served by Google Fonts for the `latin` unicode range.
